# Retained passing by witnessed periods

`fm_report_retained_pass_network_by_period(session_id,fixture_ref)` reports both sides' directed and two-way completed-pass pairs, sent/received player counts, attempted/completed period totals and pair shares. It accepts no period boundaries. Select an exact historical result from fixture discovery.

The source requires verified host native-period linkage plus an independent previously captured witness. The original `pass_event_fingerprint(events,cursor)` preserves full native flags unchanged; a mismatch remains a mismatch. The separate `pass_period_report_fingerprint` hashes every pass-family category6..11 record ending strictly before the observed cursor, sorted by event ID, with IDs, original actor/recipient slots, side, category, native clocks and only the counter-qualified decoder's selection mask0x8. This report neither consumes nor publishes other native flags, geometry or annotations. Its explicit versioned policy must change if published fields change. Exact original event-vector SHA256 remains a conservative compatibility route for older observations.

The new policy is supported by the real new Forest137388 control: all1166 pass-family IDs and all selected fields match, while flag bits0x4 and0x2 change on two records. All1145 attempts and1020 completions reconcile before and after, with exactly identical published period networks. This does not name the flag semantics or certify full raw equality. Strict and report-specific continuity states remain separately visible. A changed mask0x8, actor, recipient, category, event ID or clock still fails closed. A period extending beyond the captured prefix remains unavailable.

The wrapper captures one retained frame and event source, checks canonical historical actors and every captured individual's attempted/completed counter, links periods using the exact same retained shot/event source, and rechecks the complete source plus load epoch after projection. Native pass, attempt and clock consumer instructions are checked. Each side with failed counters stays unavailable; missing period provenance never becomes zero. It does not use a current tactical position or current roster to name historical actors.

An event belongs to a period only when `period_start <= event_start <= event_end < period_end`. Boundary ties, crossings and unobserved intervals remain explicitly unknown. Mask8 is excluded from the counter-qualified totals after fingerprint comparison. Pair share divides by all that side's completed pass events in the period; it is not a pair completion rate. There is no independent within-period aggregate counter oracle, no inferred 45-minute split, no coordinate or route claim and no tactical-causality claim.

The host observation hook preserves both witnesses from the original verified capture. An explicit authentic terminal bundle import may add a new report-specific witness computed only from that original frozen source, while preserving the old strict witness, original observation time and provenance. The retrospective retained query must never create its own historical witness from itself.
