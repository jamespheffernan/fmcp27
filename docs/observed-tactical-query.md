# Query recorded resident tactical samples

The observed-run query advertises `recorded_tactical_snapshots` automatically for a registered artifact carrying a verified recorder producer attestation. Discovery must advertise the table before it is queried. No game attachment, current tactics lookup or extra host write is involved.

The consumer verifies the immutable registered SQLite hash through the normal observed-run opening guard, then checks the source-document byte hash, selection and incarnation identity, terminal provenance hash, exact fixture and official match UID, career, fixed event cursor, collection policy and native field-label digest. The producer's validation is reused for ordered teams, sample summary, selected instruction labels, all 11 raw flag bytes and unknown bits. Unknown or stale collection policies withhold the optional tactical table; base observed data remain queryable.

A single capture supplies two rows, one for each team. It does not supply change history. `native_cursor` and `period`/score remain null: resident settings were observed within `native_cursor_window_start`/`native_cursor_window_end`, while `fixed_event_cursor` identifies the separately captured event prefix. These settings are neither a kickoff plan nor a verified fixed-tick instruction state or effective individual override. `recorded_tactical_changes` remains unavailable until there is a supported independently verified history source; this consumer never joins separate captures.

Raw flag bytes, unclassified selected bits, unmapped serialized bits, source incarnation and summary/content hashes are available as projected columns. Unnamed native instructions retain null names. A source field missing from a legacy artifact stays missing; no zeros are fabricated. The separately attested historical Forest four-snapshot/two-change source remains supported unchanged.

Validation includes a coherent synthetic source-to-recorder-to-registry-to-discovery-to-pagination control and tampered hash, fixture, career, UID, incarnation, selection, window, raw flags, labels, policy, sample summary and scope controls. Original genuine Forest rows also compare exactly. The synthetic new-policy control is not an actual live native capture: old genuine bundles lack the complete raw instruction flag bytes, and a new live-positive claim requires a future successfully recorded match.
