# Retained key-pass annotations

`fm_get_retained_key_pass_annotations` selects one exact live retained RESULT fixture. Its default view includes both sides; optional canonical team/player selectors scope the population. Pagination uses a source pin and computes all coverage before limiting rows.

The reader counts CBE flags mask2 over **all native event categories**, then compares every original-slot player's count against independently decoded native `KeyPasses` counters, including zero players. Native producer48D91A8..91CC attaches mask2 when upstream kind24 occurs; the same kind dispatches to493C75C..780 and increments player+BC. Official KeyPasses key6949686f reads that unsigned counter at2051A8. The default wire stores it at byte88, or92 for a wide PERSON reference. Seven new exact native spans guard the marker selection, dispatcher/table entry and counter/name getter; existing completed-pass/map-location guards are reused.

A whole-side mismatch remains partial. Individually reconciled canonical actors can retain explicitly scoped annotation rows; mismatching actors retain named counter diagnostics but no recipient/location rows. An annotation only receives a recipient and field position through an exact event-ID join to independently whole-side counter-qualified completed passes. Other categories and unqualified cases retain null recipients and locations. Raw related-player bytes are not interpreted outside that proof.

These are key-pass-annotated events, not direct references to a specific shot, assist or goal. There is no nearest-event/provider inference. Locations mean the official completed-pass-map event position, not a proved ball-release position; analytical equal pitch thirds are explicit derived bins, with units and human left/right unknown.

## Contract

The new module exposes `decode_key_pass_annotations(event_bytes,players,fixture,*,native_match_key,pitch_geometry=None)` and `get_retained_key_pass_annotations(bridge,session_id,fixture_ref,*,team_native_id=None,person_native_id=None,offset=0,limit=100,expected_source_id=None,coach_index=None)`. Unknown source/geometry/actor/counter coverage does not become zero. A selected individually reconciled actor can have a known count while its whole side remains partial. Rows/totals are explicitly scoped, and source pins include canonical roster, raw frame, full CBE bytes, geometry and selectors.
