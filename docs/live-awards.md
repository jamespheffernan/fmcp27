# Live award definitions

Use `fm_find_awards` to search stored names, enumerate definitions, or select canonical award/competition/nation IDs and category/period/recipient codes. Use `fm_get_award` with a returned `award_ref` to reread the exact source. Follow every `next_cursor` with identical selectors, even after an empty page. A page scans at most1000 records and returns at most100 matches; database order is not a ranking. Null and empty names remain distinct, and unknown enum codes retain their signed native value and `unmapped` state.

Every row says `record_scope=award_definition` and `winner_history={state:not_decoded,winners:null}`. A Player of the Month definition establishes neither an actual winner nor that this month's award took place. Award category (for example Highest Average Rating), period (Of The Week/Month/Season/Competition/Year/On Specified Date), and recipient type are stored configuration. They do not reproduce the complete selection/voting rules or current scheduling. No award date is presented as an actual presentation date.

Names and short names are stored native strings, not reconstructed localized display text. Nation, continent and competition links are independent nullable canonical identities with native IDs; they are not nationality restrictions inferred from an award's name. Duplicate names remain separate records. Use existing competition tools with the returned canonical native ID to inspect competition context.
